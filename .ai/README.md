# Agent Continuity Packet

This tracked directory is the compact handoff layer for long-running work on
AI ArchViz Platform. Read it before work and update it only when verified
project state changes.

Reading order:

1. [STATUS.md](STATUS.md)
2. [NEXT_TASK.md](NEXT_TASK.md)
3. [ARCHITECTURE.md](ARCHITECTURE.md)
4. [CONTRACTS.md](CONTRACTS.md), [DECISIONS.md](DECISIONS.md), and
   [VALIDATION.md](VALIDATION.md) as relevant

This packet records intent, decisions, status, and verification evidence. The
authoritative behavior remains in repository source, schemas, tests, and
canonical `docs/` files.

Never record secrets, machine-specific paths, generated `.max` files,
`.workspace/` contents, transient logs, or copied terminal output here.
